# <stack> — card (copy to `<stack>.md`; user-maintained, optional)

Read by the design skill at project and module level when the detected stack matches the file name
(`react-ts.md`, `flutter.md`, `swiftui.md`, `go.md`, …). Keep it to what changes a decision.

- **Conventional layout** — folders, what belongs where, the framework's own convention.
- **Layering idiom** — the dependency direction this ecosystem expects and how to enforce it.
- **State and lifecycle** — where state may live, lifecycle rules.
- **Concurrency** — the model and its hard rules.
- **Errors** — exceptions, results, typed errors.
- **Dependency injection** — the idiom and the tool, if any.
- **Testing** — tools per layer, fakes, the integration harness.
- **Platform rules** — store, browser, runtime constraints that veto designs.
- **Known-good references** — 3–5 links, one line each.
