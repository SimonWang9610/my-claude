# Delegation

- **A fresh agent every time**; a follow-up names the earlier artifact and the delta.
- **Brief** (`my-workflow:spec-<name>`; Copilot: `spec-<name>`): where · what · materials (the
  `workflow.yaml` path, facts found; sliced paths) · done when (architect: the
  design check passes · tester: tests returned, seen failing · reviewer: the report). Never your
  reasoning, nor what the agent's definition already says.
- **Tests before code** — the tester writes the acceptance tests before implementation starts; you
  then implement against them and never edit them: a wrong-looking one → ask.
